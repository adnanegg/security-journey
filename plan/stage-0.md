# Stage 0: Foundations (4 weeks, ~40h)
Day format: 15 min recall, 75 min lab, 30 min log + commit.

## Week 1: Linux and shell
OverTheWire Bandit (levels 0-20), Linux Journey (free). Log commands you didn't know.

## Week 2: Networking
TCP/IP, DNS, ports, TLS basics. Professor Messer free Network+ videos (skim what you know), Wireshark on your own traffic, nmap against your own VM.

## Week 3: HTTP and web basics
MDN HTTP docs, install Burp Suite Community, proxy your own Next.js/Supabase app and read every request.

## Week 4: Python and bash for security
Automate the Boring Stuff (free online). Write a port scanner and a simple HTTP request tool.

## Gate
Diagnostic + timed exam + oral defense + one published write-up.
